# StudioSpace — Backend Server

**Project:** StudioSpace

StudioSpace is a creative studio marketplace backend that powers studio listings, user bookings, reviews, and host management.

## ✨ Key Features

- **Studio Management:** Create, view, update, and manage creative studio listings.
- **Studio Discovery:** Retrieve available studios and featured studio information.
- **Booking System:** Create booking requests and manage booking records.
- **Booking Management:** Hosts can confirm, reject, and complete booking requests.
- **Booking Cancellation:** Customers can cancel eligible bookings.
- **Reviews and Ratings:** Manage studio reviews and ratings.
- **Image Upload:** Support image uploads for studio listings.
- **Newsletter:** Handle newsletter subscriptions.
- **Data Management:** Store and retrieve application data using MongoDB.

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git
- MongoDB database

### 1. Clone the Repository

```bash
git clone YOUR_BACKEND_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd studio-space-server
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root and configure the environment variables required by the application.

### 5. Run the Development Server

```bash
npm run dev
```

The backend server will start using the configured port.
